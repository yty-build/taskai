# Journal

## 2026-08-30 — Interface concept page (docs/interface_concept.html)

- Built the TaskAI UI concept as a living, keyboard-driven single-file HTML demo rather than static mock screens. Direction: "OLED cockpit glass" — dark-only, glass panels, one ion-blue accent, amber reserved for attention, red reserved for Destroy, HUD-style corner-bracket selection.
- Fonts are embedded as base64 woff2 data URIs (Switzer UI / Martian Mono HUD labels / Geist Mono terminal, ~137KB total) because artifact CSP blocks font CDNs. Sources: Fontshare API for Switzer, Google Fonts (latin subset URL requires a browser User-Agent header) for the monos.
- Python urllib fails behind the local proxy (self-signed cert in chain); curl works. Use curl for downloads in this environment.
- Playwright MCP blocks `file://` — serve the page with `python3 -m http.server` on localhost instead. Screenshots land in the repo root (`./name.png`); move them to the scratchpad to keep the repo clean.
- Feed engine gotcha: script loops must restart at an op that opens a visual block (a spinner or tool call), never at a `⎿` result line, or the loop orphans output. Same class of bug: cycling an arrow-select option that has a side effect (opening the repo explorer) must not fire while cycling *past* it — keep side-effect options last.
- Demo data must stay internally consistent: harness live counts, tree states, and home-row aggregates are all derived from one session list, so a "needs setup" harness cannot also have a live session (that's why the demo adds Aider as the unconfigured harness instead of Grok, which the UX doc uses).
- Four-lens critique workflow (aesthetic / CSS craft / product fidelity / interaction) surfaced 44 findings; ~35 applied. Highest-value: loop variance via `{{n:a-b}}`/`{{pick:…}}` templating in feed scripts (verbatim repetition kills the "living terminal" illusion), aurora hotspots must sit *under* the glass panels or backdrop-blur reads as flat cards, and ion must be reserved for live/selection (ready-states go dim).
- T direction: the terminal build must be a 100% replica of the HTML, building custom modules where stock TUI widgets fall short. Replica mode (`b`) renders the same state cell-true; pegged stack: Rust — ratatui + crossterm, custom `aurora.rs` (per-cell truecolor gradient field), `glass.rs` (alpha-composite panel fill over pre-blurred aurora), `brackets.rs` (⌜⌝⌞⌟ tick rows), `pulse.rs` (eased animation, DEC 2026 synchronized output), `vtpane.rs` (portable-pty + vt100 grid blit), optional `pixels.rs` (Kitty graphics/Sixel). Glass translucency is replicable because the backdrop is known — per-cell compositing is just math.
